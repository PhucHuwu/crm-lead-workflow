# Nguồn hình hướng dẫn

- `claude-code-open-folder-real.png`: ảnh cắt menu No folder đang mở trên Mac, hiển thị Open folder…; loại vùng Recent chứa các dự án khác. Đây là menu trong Claude, không phải hộp thoại chọn thư mục của macOS.

- `claude-code-no-folder-real.png`: ảnh chụp Code Local trên Mac khi chưa chọn thư mục, nhãn thực tế là No folder. Cắt bỏ vùng tài khoản/thống kê; dùng để đối chiếu trước/sau với `claude-code-local-real.png`.

- `github-download.png`: ảnh chụp trang kho GitHub, không phải giao diện Claude.
- `folder-map.svg`, `copy-files.svg`, `unzip.svg`, `email-flow.svg`: sơ đồ thao tác/nghiệp vụ, không phải screenshot hệ điều hành hay ứng dụng.
- `code-local.svg`: sơ đồ thao tác Code → Local → Select folder, đối chiếu tài liệu https://code.claude.com/docs/en/desktop-quickstart. Không phải ảnh chụp Claude Code.
- Các ảnh Chat Projects/Add to project hoặc trang download không được dùng làm hình đối chiếu giao diện Code.

`claude-code-tabs-real.png` và `claude-code-local-real.png`: cắt từ ảnh chụp Claude Desktop đang mở Code trên Mac ngày 2026-10-08. Đã loại vùng tên tài khoản/thống kê. Không biết số phiên bản ứng dụng. Ảnh local hiển thị Bypass permissions của máy chụp; chú thích hướng dẫn người mới chọn Manual. Chưa chụp hộp thoại Select folder hoặc yêu cầu cấp quyền.
